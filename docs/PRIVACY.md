# 隐私与数据说明

读日和没有账号系统、统计埋点、广告或自建后台。

## 网页与注音

用户主动开启后，扩展读取当前网页可访问的文字，在扩展内部使用随包附带的 Kuromoji / IPADIC 词典分词和生成假名。此过程不把网页内容发送到互联网。输入框、可编辑区域、代码及已有 ruby 注音会被跳过。

## 翻译服务

- 默认 MyMemory：点击词语后，仅将该词的原形发送至 `https://api.mymemory.translated.net/get`，目标语言为简体中文。服务方会像普通网络请求一样收到 IP 等连接信息，适用其自身条款与隐私政策。
- Microsoft Translator：用户选择并配置后，仅将选中词语发送至微软官方 `https://api.cognitive.microsofttranslator.com/translate`。密钥通过请求头发送给微软。
- Bing 网页模式：扩展不自动请求翻译。用户点击链接后，词语随 URL 参数传给 Bing 翻译网站。
- 网页地址、页面标题和收藏例句不发送给翻译接口。无自动全文翻译或后台上传。机器翻译结果不是权威词典释义。

服务说明：[MyMemory](https://mymemory.translated.net/doc/)、[Microsoft Translator](https://learn.microsoft.com/azure/ai-services/translator/text-translation/overview)、[Bing 翻译](https://www.bing.com/translator)。

## 收藏与密钥

收藏包含表层词、原形、假名、罗马音、词性、释义、学习状态、笔记、收藏时间，以及用户收藏位置的文本片段、页面标题和网址。全部存于当前浏览器的 `chrome.storage.local`，不跨设备同步。扩展限制为 5000 词；浏览器存储配额仍可能先达到，届时会显示错误。

微软密钥和区域也保存在扩展本地存储，不加密，因此不适合存储他人共享的敏感生产凭据。网页内容脚本不能直接读取该存储；配置接口也限制为扩展自己的页面。JSON / CSV 单词导出不含密钥。JSON 备份含收藏的原文网址和片段，请按个人需要保管。

移除单词会删除对应记录。卸载扩展或清理扩展数据会删除本地数据；请预先导出备份。翻译缓存仅在服务工作线程内存中保存，最多 300 个结果，线程结束后消失。

## 权限

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户点击图标或按快捷键后临时访问当前页面 |
| `scripting` | 在用户开启的当前页面注入注音和查词界面 |
| `storage` | 本地保存收藏和偏好设置 |
| `tts` | 调用浏览器 / 系统的日语语音进行朗读 |
| 两个翻译域名的主机权限 | 由扩展工作线程调用所选翻译服务 |

没有请求所有网站的持续访问权。语音提供方可能是本地或浏览器安装的远程语音，取决于当前环境；没有日语语音时会明确提示。
