# 隐私与数据说明

适用于 v0.2.0。读日和没有账号系统、统计埋点、广告或自建后台。

## 网页与本地分析

用户主动开启后，扩展读取当前网页可访问的文字，使用随包附带的 Kuromoji / IPADIC 生成日语假名，使用 Compromise 处理英语，并在本地运行主语 / 话题与主干识别规则。以上分析不向互联网发送网页文字。输入框、可编辑区域、代码及已有 ruby 注音会被跳过。

## 翻译与可选中文标注

- 普通查词：点击词语后，将该词的原形及源语言（日语或英语）发给所选翻译服务，目标为中文。
- **原文上方显示中文默认关闭**，日语和英语有各自的开关。开启某一语言后，扩展会把可见区域及附近的不同词语逐个发送至所选翻译服务，无需逐词点击；不会把整段文本作为一次请求发送。每轮最多请求 120 个词，重复词复用结果，到达上限后可手动继续，失败会暂停。
- 关闭中文标注会停止后续排队查询并隐藏标注；已发出的请求不能撤回。开关属于全局偏好，会应用到已开启阅读辅助的网页。
- MyMemory：请求 `https://api.mymemory.translated.net/get`。服务方会像普通网络请求一样收到 IP 等连接信息，适用其自身条款与隐私政策。
- Microsoft Translator：配置后请求微软官方 `https://api.cognitive.microsofttranslator.com/translate`，密钥通过请求头发送给微软。
- Bing 网页模式：扩展不自动请求翻译，不提供原文上方中文。用户点击链接后，词语及源语言随 URL 参数传给 Bing 翻译网站。
- 网页地址、页面标题、收藏例句、笔记和复习记录不发送给翻译接口。逐词机器翻译可能缺少上下文，也不是权威词典释义。

服务说明：[MyMemory](https://mymemory.translated.net/doc/)、[Microsoft Translator](https://learn.microsoft.com/azure/ai-services/translator/text-translation/overview)、[Bing 翻译](https://www.bing.com/translator)。

## 收藏、复习与密钥

收藏包含语言、表层词、原形、假名、罗马音、词性、释义、学习状态、笔记、收藏时间，以及收藏位置的文本片段、页面标题和网址。背词新增复习阶段、下次复习时间、最近复习时间、次数、遗忘次数和最近一次评分的去重标识。全部保存在当前浏览器的 `chrome.storage.local`，不跨设备同步。上限 5000 词；浏览器存储配额仍可能先达到，届时会显示错误。

微软密钥和区域也保存在扩展本地存储，不加密。网页内容脚本不能直接读取该存储；配置和复习管理接口仅限扩展自己的页面。JSON / CSV 单词导出不含密钥。JSON v2 备份含收藏的原文网址、片段和复习进度，请按个人需要保管。

移除单词会删除对应记录及其复习进度。卸载扩展或清理扩展数据会删除本地数据；请预先导出备份。翻译缓存仅存于内存：工作线程最多 800 项，网页的中文标注缓存最多 1000 项；分别在工作线程结束或网页关闭 / 刷新后消失。

## 权限与朗读

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户点击图标或按快捷键后临时访问当前页面 |
| `scripting` | 在用户开启的当前页面注入阅读辅助与查词界面 |
| `storage` | 本地保存收藏、复习进度和偏好设置 |
| `tts` | 调用浏览器 / 系统的日语或英语语音进行朗读 |
| 两个翻译域名的主机权限 | 由扩展工作线程调用所选翻译服务 |

没有请求所有网站的持续访问权。朗读时，选中的词语交给系统或浏览器语音提供方；其语音可能是本地或安装的远程语音，取决于环境。没有对应语言语音时会明确提示。
