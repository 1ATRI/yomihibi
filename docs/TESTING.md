## 测试与真实服务的区别

自动化测试运行真正的扩展代码及词典，**外部翻译响应模拟**，用于稳定测试成功、错误、保存和模式切换。不能据此保证任意网络下 MyMemory 可用，也不能保证未配置的微软密钥 / 资源有效。

为了在无浏览器工具栏的 headless 环境测试注入，脚本复制 `dist/` 到测试目录，只给副本增加 `http://127.0.0.1/*` 权限。发布 manifest 不增加此权限，仍靠用户点击图标 / Alt + J 获得 `activeTab`。因此，生产包的浏览器工具栏授权动作还需安装后人工确认。

日语 TTS 依赖实际安装的系统 / 浏览器语音；自动化未验证音频听感。Firefox、商店发布和所有第三方站点的兼容性不属于已验证范围。

## 已知限制

- 以文本节点为分词边界，跨节点词语可能分错。
- 自动词典注音不能保证人名、多音字或新词正确。
- 不处理图片、PDF、跨域 iframe 和封闭 Shadow DOM。
- React 等频繁重写正文的页面可能覆盖注音，需要重新开启或刷新。
- 单词本不跨设备同步，上限 5000 词，仍受浏览器存储配额限制。
- 机器翻译可能缺少上下文；免费接口存在额度、网络及可用性变化。
