## 自动化与真实环境的区别

自动化实际运行扩展代码与词典，**外部翻译响应模拟**，用于稳定验证成功、错误、语言参数、保存和模式切换；不能据此保证免费服务在任意网络和配额条件下可用，也没有验证用户尚未配置的微软资源。

headless 测试复制 dist，只对测试副本增加 `http://127.0.0.1/*`，以注入本机测试网页；正式包仍依赖点击图标 / Alt + J 获取 activeTab。生产包的浏览器工具栏授权动作需安装后人工确认。

朗读依赖实际安装的日语 / 英语语音；自动化未验证音频听感。Chrome / Edge 共用 Chromium 平台，但本次流程使用 Playwright Chromium，未在每个发行渠道重复安装测试。Firefox、扩展商店审核、任意第三方页面兼容性不属于已验证范围。

## 已知边界

- 主干采用启发式规则，复杂从句、倒装、省略、歧义和跨节点结构可能不准确；测试例句通过不是语言准确率评测。
- 人名、多音字和新词可能注音错误，跨节点词语可能分错。
- 不处理图片、PDF、跨域 iframe、Shadow DOM 内文。
- 频繁重写正文的页面可能覆盖标注，需要重新开启或刷新。
- 逐词中文标注使用外部服务额度；关闭后已发出的请求不能撤回。
- 复习是固定档位调度，未验证学习效果；收藏最多 5000 词、不跨设备同步，且受浏览器本地存储配额限制。
