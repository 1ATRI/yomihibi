# 项目说明

## 目标

帮助中文使用者在浏览日文网页时减少来回查词：看见假名、读懂词语、保留生词，形成阅读与复习的连续体验。

项目：**读日和（Yomihibi）**；代码仓库：<https://github.com/1ATRI/yomihibi>；首版：0.1.0；浏览器：Chrome / Edge。

## 需求与验收

| 原始需求 | 实现 | 验收方式 |
| --- | --- | --- |
| 页面汉字上方标假名 | Kuromoji / IPADIC 离线分词 + ruby 注音 | 日语句子显示读音；送假名保留；关闭恢复原文 |
| 点击词语有翻译、读音、意思 | Shadow DOM 查词卡片，MyMemory / 微软翻译 / Bing 链接 | 点击词语显示假名、罗马音、词性、原形、中文结果和朗读按钮 |
| 独立单词收藏页 | 本地单词本、搜索、学习状态、笔记、备份 | 点击收藏进入单词本；刷新后仍在；导出后可导入恢复 |
| GitHub 项目与文档 | 公开仓库、README、使用 / 架构 / 测试 / 隐私文档、Release | 可克隆构建，下载 ZIP 并加载 |

## 首版范围

主动开启当前页面，无后台自动监控。默认免密钥翻译，用个人微软接口配置扩展选择。机器翻译提供阅读辅助，不构建权威辞书。收藏以浏览器本地存储为准，不设账户。

## 下一步候选

以下是规划，未在当前版本实现：

- 允许用户为指定站点授予自动开启权限，并支持站点排除列表。
- 集成本地日中释义词典，降低查词对网络的依赖。
- 人名与自定义读音覆盖、按熟悉程度隐藏假名。
- 间隔复习、每日复习队列和更方便的 Anki 字段模板。
- Firefox 适配与浏览器扩展商店发布。
- 按需适配开放 Shadow DOM 与 iframe，改善复杂网页兼容性。

不预先承诺时间表。欢迎通过 [Issues](https://github.com/1ATRI/yomihibi/issues) 提供日文示例、网页地址、预期读音和浏览器版本。
