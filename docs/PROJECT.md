# 项目说明 · 第二版

读日和（Yomihibi）帮助中文使用者阅读日语与英语，从看懂词语与句子结构，到收藏和复习形成闭环。当前版本 0.2.0，支持 Chrome / Edge Manifest V3。

## 第二版需求与验收

| 需求 | 实现与边界 | 验收 |
| --- | --- | --- |
| 日语主语高亮 | 依据名词词组与助词规则；は 另标话题 | 私は本を読みます / 猫が魚を食べます |
| 日语句子主干 | 标记候选话题 / 主语、对象、句末谓语，并提供卡片摘要 | 不补造省略主语，可关闭 |
| 英文上方中文，可选 | 按可见词语查询，独立开关、去重、限额、进度 | 英文开关不影响日文，关闭恢复 |
| 日文可选中文 | 与假名开关独立，可同时显示 | 日文中文和英语中文各自开关 |
| 英语查词、主干和收藏 | Compromise 词性 / 词组分析，英文来源翻译和语音 | 英文点击得到中文并保存为 en 记录 |
| 收藏背词 | 翻面、自评、正反方向、到期队列、忘词重现 | 进度刷新保留，JSON 可恢复 |

## 保留的第一版能力

离线日语分词、送假名对齐、查词和 Bing 链接、本地收藏、原文来源、搜索排序、笔记、掌握状态、JSON / CSV 备份、动态内容扫描、关闭恢复、Alt + J、最小网页权限。

## 当前边界

主干属于本地规则候选结果，不是完整句法树。文本节点为边界，复杂从句、倒装和跨标签句子可能误判。没有接入云端大模型来上传全文解析，也没有离线日中 / 英中释义大词库。

翻译仍依赖服务网络与配额。中文标注默认关闭，开启时发送可见词语原形。复习采用确定的档位间隔，不声称是个性化记忆预测算法。
