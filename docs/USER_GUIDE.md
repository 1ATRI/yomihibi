# 读日和 0.2.0 使用指南

## 安装与升级

从 [Releases](https://github.com/1ATRI/yomihibi/releases/latest) 下载 `yomihibi-v0.2.0.zip`，解压到长期保留的目录。在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 开启开发者模式，点击「加载已解压的扩展程序」，选中包含 manifest.json 的目录。

**升级前导出 JSON 备份。** 用新版文件覆盖原加载目录，点击扩展管理页的刷新，再刷新网页。不要先卸载，卸载会删除数据。换目录加载可能产生新的扩展 ID，届时导入备份即可。0.1.0 词语会保留原 ID、笔记和掌握状态，语言默认为日语。

## 阅读开关

打开普通日文或英文网页，点击插件图标打开阅读辅助，或用 Alt + J。刷新 / 重新导航后需要再次开启。选「自动识别」「日语」或「英语」；自动识别不合适时，手动选择更可靠。

假名开关只控制日语读音。设置页可将标注字号调到正文的 45%～85%。不会删除网页原有 ruby，也跳过输入框、编辑区域和代码。

## 主语与句子主干

两个开关分别控制「主语 / 话题高亮」和「谓语、宾补语标记」。页面右下角有图例，点击单词时卡片内也会显示所在句的候选结构。

| 标记 | 意思 | 示例 |
| --- | --- | --- |
| S 主语（蓝） | 谁 / 什么在做动作 | The student / 猫が |
| T 话题（紫） | 日语句子讨论的话题 | 私は |
| V 谓语（橙） | 动作或状态 | reads / 読みます |
| O 宾语（绿） | 动作涉及的对象 | a book / 本を |
| C 补语（金） | 英语系动词后的状态等 | is happy 中的 happy |

日语「は」标为话题，不直接等同于主语。省略的主语不会被补造。规则识别适合常见句型，复杂句、从句、倒装及跨标签句子可能误标或不完整，请结合上下文判断。

## 原文上方的中文

弹窗或设置中分别开启「日文上方显示中文」「英文上方显示中文」。两个开关默认关闭，相互独立；日语可以同时显示假名和中文。

开启后会向所选翻译接口逐词发送可见区域及邻近 80px 内的词语原形。重复词复用，最多 2 个请求并行；每轮最多 120 个请求，页面右下角显示进度。达到上限可点击「继续 120 词」，请求失败后暂停并提供「重试」。关闭开关或阅读辅助会移除中文并停止后续调度，已经发出的请求无法撤回。

自动中文需要 MyMemory 或 Microsoft Translator；Bing 网页模式会提示切换服务。长释义在原文上方缩略显示，悬停中文可看全文，点击词语可查看完整释义。逐词翻译无法保证整句语义。

## 查词、发音与收藏

点击词语显示语言、词性、原形、中文机器翻译、句子主干摘要；日语还有假名和罗马音。点击朗读调用日语或英语语音。没有对应语音包时会提示，可使用 Bing 的发音。

翻译结束后可收藏，失败时也能先收藏再补充释义。Esc / 关闭按钮 / 点击外部关闭卡片；Tab 聚焦词语后 Enter 或空格查词。若原词是网页链接，可使用 Ctrl / ⌘ + 点击打开原链接。

默认 MyMemory 免密钥，但有配额 / 网络限制。可在设置填写自己的 Azure Translator 密钥和区域；Bing 模式使用外部网页。密钥不是 Bing 账号密码。

## 单词本与备份

支持按日语 / 英语、学习中 / 已掌握筛选；搜索词语、原形、假名、罗马音、释义或笔记。点击单词编辑笔记 / 释义；移除收藏需再点一次确认。

同语言相同 ID 去重，不覆盖已有笔记。日语沿用原形 + 读音 ID，英语使用 en + 小写原形。不同活用或原形识别误差可能形成不同记录。

- JSON：保存所有词语、笔记、学习状态和复习进度；支持 v1 / v2 导入，重复词保留现有数据。
- CSV：便于表格与 Anki 字段映射，不用于恢复扩展数据。
- 导入文件最多 8 MB，合并后最多 5000 词；还受浏览器存储配额限制。

## 收藏背词

1. 在单词本或弹窗点「开始背词」。
2. 选择日语 / 英语 / 全部、到期与新词 / 全部收藏、正向 / 反向、本轮 10 / 20 / 50 词。
3. 先回想，再点「翻面」或按空格。答案、读音和例句在翻面后显示。
4. 按 1 忘记、2 模糊、3 记住、4 很熟悉；进度立即保存在本机。

忘记的词在本轮队尾重现；记住后按 1、3、7、14、30、60、120 天逐档延长。模糊安排 10 分钟后，很熟悉前进两档。随时可结束，已作出的评价仍保存。

没有中文释义的词会跳过，请先补充。已掌握的词不进入到期队列，可在全部模式复习；点「重新学习」会重新进入到期队列。收藏与学习记录不跨设备同步。

## 常见问题

**没注音 / 没高亮？** 确认页面语言与选项。浏览器设置页、扩展商店、图片、PDF 和 iframe 不支持；高度动态页面可能需要刷新后重新开启。

**中文不显示？** 检查对应语言的开关与翻译服务。Bing 网页模式不支持行间中文。查看右下角是否提示配额、网络、达到本轮上限；可重试或继续。

**读音、主干或翻译有错？** 词典和规则分析都有边界，逐词机器翻译缺少上下文。请把标记作为辅助，在单词本保存自己的正确释义。

**背词页没有词？** 可能没有到期词、筛选了另一语言、都标为已掌握，或收藏缺少释义；可以切换全部模式或补充释义。
