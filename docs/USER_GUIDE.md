# 使用指南

## 1. 安装

从仓库 [Releases](https://github.com/1ATRI/yomihibi/releases/latest) 下载 `yomihibi-v0.1.0.zip`，解压到一个长期保留的文件夹。不要在加载后移动或删除该目录。

Chrome：地址栏输入 `chrome://extensions/`。Edge：输入 `edge://extensions/`。

开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。将插件固定到工具栏，便于随时开启。

源码安装方式：`npm ci` → `npm run build` → 加载 `dist/`。

## 2. 网页注音

打开日文网页，点击读日和图标，再开启右侧开关。首次加载离线词典可能需要几秒，网页底部会显示进度提示。

- 汉字上方出现平假名。词典不知道读法的词语保留原字，避免凭空注音。
- 点击弹出面板中的假名复选框可隐藏注音，查词仍可使用。
- 设置页能将假名字号调整到正文的 45%～85%。
- `Alt + J` 切换当前网页阅读辅助；若快捷键被占用，可在浏览器扩展快捷键设置中调整。
- 刷新或重新导航后需要再次开启。关闭时移除本插件添加的注音，不移除网页原有注音。

## 3. 点击查词

点击日文词语，卡片会显示假名、罗马音、词性，以及有变化时的原形。中文释义查询的是原形，因此能帮助认识动词活用。

- 「朗读」调用系统或浏览器的日语语音。
- 「收藏单词」在释义请求结束后可用；请求失败也能收藏词语，在单词本手工补充释义。
- 「Bing 翻译」打开 Bing 网页并带入词语。
- `Esc`、卡片关闭按钮或点击其他位置可关闭卡片。
- 单词支持键盘 Tab 聚焦，Enter / 空格查词。
- 页面链接内的词语可正常查词；需要打开原链接时，使用 Ctrl / ⌘ + 点击。

## 4. 选择翻译服务

在插件弹窗点击齿轮打开设置。

| 服务 | 配置 | 使用方式 |
| --- | --- | --- |
| MyMemory | 无需密钥 | 默认自动返回中文机器翻译，有服务端额度与频率限制 |
| Microsoft Translator | 填写 Azure Translator 密钥和资源区域 | 自动调用微软官方翻译接口 |
| Bing 网页 | 无需密钥 | 不自动发送请求，手动点击卡片中的 Bing 链接 |

微软密钥来自你自己的 Translator 资源，不是 Bing 账号密码。区域依资源配置填写，例如 `eastasia`；全局资源可按微软文档留空。保存后密钥仅存于当前浏览器的扩展存储，不会包含在单词备份中。

## 5. 管理单词本

从弹窗点击「我的单词本」，或从查词卡片打开。

1. 搜索支持词语、原形、假名、罗马音、中文释义和笔记。
2. 点击「标为掌握」切换学习状态；随时可以重新学习。
3. 点击单词打开详情，编辑中文释义和自己的笔记。
4. 详情中提供原网页来源链接。若单词来自内置练习，来源不会保存为外部链接。
5. 「移除收藏」需要再点击一次确认，以免误删。

同一原形和读音不会重复收藏，再次收藏也不会覆盖已有笔记。上限为 5000 词；大量长笔记可能提前达到浏览器存储配额。

## 6. 导入导出

- **JSON**：完整备份全部收藏，包括笔记、学习状态、例句和来源，之后可重新导入。
- **CSV**：方便 Excel 查看，也可以在 Anki 导入时映射字段。CSV 不用于恢复扩展数据。
- 导入 JSON 时合并词语，保留已有重复词的释义和笔记，不覆盖。
- 单个导入文件限制 8 MB；最多导入 5000 词，合并后也不能超过此上限。

浏览器之间不会自动同步。想迁移到另一台电脑，需要从原浏览器导出 JSON，再到新浏览器导入。

## 常见问题

**开启后没反应？** 普通 HTTP / HTTPS 日文网页才支持注音。浏览器内置页面、扩展商店、PDF、图片或嵌入的跨域内容无法处理。插件更新后请刷新网页，再次开启。

**为什么有些词的假名不对？** 注音依赖词典和自动分词，人名、多音字和新词可能误判；跨节点排版会影响上下文。请结合原文确认。

**为什么无法翻译？** 可能是网络超时、免费服务额度耗尽或配置错误。卡片会显示具体提示。可切换微软接口、使用 Bing 链接，或先收藏后补充释义。

**为什么不能朗读？** 浏览器没有找到日语语音。请在系统语言设置安装日语语音包，或打开 Bing 使用网页提供的发音。

**能否离线用？** 注音、读音 / 原形 / 词性展示和收藏管理可离线；新的中文翻译需要联网。朗读是否离线取决于安装的语音。

**能不能直接安装 Firefox？** 当前只提供 Chrome / Edge 的 Manifest V3 构建，Firefox 还没有适配。
